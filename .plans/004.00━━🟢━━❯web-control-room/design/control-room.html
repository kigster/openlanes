          How this works

          Draft copy, to be replaced by the author's.

          This is a distributed software factory. Every machine that runs agentilda on this repository and points at the same Redis works on the same set of plans, side by side.

          You join by sharing $REDIS_URL. There is no other mechanism: no invitation, no accounts. Anyone who connects to that Redis from a clone of the same GitHub repository is in, and shows up here as a machine of their own.

          Nobody can be kept out or kicked out. This is not a policy enforcement system. It assumes everyone around is friendly: other machines are shown read only, and a plan one machine is working on is left alone by the rest, by agreement, not by force.

          Stop All Local stops the agents on this machine only. The other machines keep running.
