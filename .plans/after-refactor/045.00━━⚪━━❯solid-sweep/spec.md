# SOLID Sweep

Source: GitHub issue #95 (S19), rescoped on 2026-10-24 by `docs/decisions/decisions-on-dry-rb-architecture.md` (A1, A2, A8 to A13, and "What earlier plans already settled").

## What we are trying to achieve

A codebase that reads crystal clear, wired as a dry-rb application, with no change in behaviour.

- dry-system registers every component from `lib/` through the existing Zeitwerk loader; collaborators arrive by `Deps[...]`; providers own Redis, GitHub, Linear, the event bus, the logger and OpenTelemetry (A1).
- Coding agents are components under `adapters.<name>`, resolved by name; the hand-written registry hash goes (A2).
- Every class at most 100 lines, every method at most 10, at most 4 parameters, AbcSize at most 20, enforced by rubocop with no exemptions left. Metaprogramming only where it declares: `Data.define`, class-level DSLs, `def_delegators`, `define_method` over a literal list, and `inherited` or `included` hooks that set per-class instance variables (A8).
- Behaviour is frozen: CLI flags and output, `.plans/` files and API responses unchanged, existing spec assertions untouched (A9).
- The bare `Thread.new` sites move to concurrent-ruby; fallible operations return dry-monads `Result`; a vendor-neutral `Judgment` port, with Jev only when `TYPESAFE_API_KEY` is set (S15, S19).
- Logs and traces from one set of dry-monitor instrumentation events: SemanticLogger to `log/openlanes.log`, and spans through `opentelemetry-api` only (A13). Spans are new behaviour and land in their own pull request.

## Why it matters

`engine/dispatcher.rb` is 2,671 lines with 142 methods, and 58 classes exceed the 100-line limit that `.rubocop.yml` already states. Tasks (053.00), `ol new` (054.00) and `ol init` (055.00) all build on swappable components that do not exist yet.

## What already exists

- The `038.00` seams: `EventBus`, `Clock`, `Process`, the adapter capability contract.
- Facades per namespace; dry-monads and concurrent-ruby in the gemspec; the `Engine::Upkeep` facade from #127 as the pattern for a split.
- `ol uml` and the frozen `docs/architecture/before/` snapshot (052.00), regenerated by every pull request here.
- The global lock (034.00): this plan runs alone.

## What research needs to settle

- The seam order after Dispatcher, Executor, PlanState and RunWorkflow (A11 says the rest by size).
- How dry-system's component dirs map onto the Zeitwerk-collapsed `support/` and `cli/<command>/` directories.
- Which of the 24 `Thread.new` sites need a pool and which a `TimerTask`.
