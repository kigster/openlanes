# Bundled Skills

_The agent skills OpenLanes ships and installs with `openlanes skills install`._

**Up:** [Getting Started](Getting-Started.md)

______________________________________________________________________

Install them into `~/.agents/skills` with `openlanes skills install`. The `openlanes` skill loads first; the others name it as a prerequisite.

| Skill                                                                                                       | When it loads                                                                                                                                                                                                                                                                                                  |
| ----------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`openlanes-documents`](https://github.com/kigster/openlanes/blob/main/skills/openlanes-documents/SKILL.md) | The files inside a openlanes plan folder: what spec.md, plan.md, blocked.md, pull-requests.md and the closing documents are for, the exact formats openlanes parses, and a template for each.                                                                                                                  |
| [`openlanes-run`](https://github.com/kigster/openlanes/blob/main/skills/openlanes-run/SKILL.md)             | Start the openlanes factory with `openlanes start` (engine plus control room, up until Stop Local Workers or Ctrl-C, questions answered and plans created on the page), or run openlanes's specialist agents over named plans to a fixed point with `openlanes run <NNN,...>` and clear blocked plans with \`open… |
| [`openlanes-setup`](https://github.com/kigster/openlanes/blob/main/skills/openlanes-setup/SKILL.md)         | Set a project up on openlanes: check the prerequisites, run `openlanes init`, install the skills, and create the first plan.                                                                                                                                                                                   |
| [`openlanes-spec`](https://github.com/kigster/openlanes/blob/main/skills/openlanes-spec/SKILL.md)           | Create a openlanes plan and write its spec.md: choose the lane (research, planning, building) and depth, and record implementation suggestions, requirements, done criteria and verification.                                                                                                                  |
| [`openlanes-status`](https://github.com/kigster/openlanes/blob/main/skills/openlanes-status/SKILL.md)       | Report where openlanes plans stand: every plan's state and pull requests, the INDEX.md, one plan's agent history from state.json, the messages in its mailbox, or the live control room.                                                                                                                       |
| [`openlanes-sync`](https://github.com/kigster/openlanes/blob/main/skills/openlanes-sync/SKILL.md)           | Bring openlanes's `.plans/` back in step with reality: rename folders whose names lag their contents, prefix pull request titles with their plan's `[NNN.MM]`, adopt orphan PRs as retroactive plans, and export plans to Linear.                                                                              |
| [`openlanes`](https://github.com/kigster/openlanes/blob/main/skills/openlanes/SKILL.md)                     | The openlanes software factory (`openlanes` CLI) that drives `.plans/` folders through spec → plan → build → review with specialist agents.                                                                                                                                                                    |
